# BlenderMCP 打印前体检提示词（本机适配版 v2）

> 来源：ChatGPT 生成的逐项体检提示词，经本机（Blender 5.2 + 混元图生3D + print_gate 闸门链）适配。
> 用途：本技能（hunyuan-3d-multiview）段B 的规范化检查清单。配合段C（print_gate 数值闸门）构成"视觉+数值"双体检。

## 本机适配要点（执行前必读）

1. **执行机制**：MCP（或 blender-direct-tcp 直连 9876）只能执行代码，**看不见视口**。所有视觉检查必须：`execute_blender_code` 摆相机 → 渲染特写到 PNG → 用 Read 工具看图判断。禁止凭想象填写检查结果。
2. **几何数字检查**：Blender 5.2 的 `bpy.ops.mesh.print3d_check_all` **裸装不可用**（实测；扩展已装回，见 pitfalls.md 第 17 条）。数值类检查（非流形边、边界边、连通块、体积正负、法线朝向）一律跑：
   ```bash
   "C:/Program Files/Blender Foundation/Blender 5.2/blender.exe" --background \
     --python scripts/print/repair_for_print.py -- --mode diagnose --glb <model>.glb
   ```
   其输出即"实际执行的检查"，不是视觉判断。
3. **焊接前置**：混元 GLB 沿 UV 接缝拆顶点，不焊接就会看到海量假开放边（实测 15.5 万条假象 vs 焊接后 0）。diagnose 已含焊接逻辑，视觉检查不需要，但**读它的数字前先确认跑的是焊接后的结果**。
4. **壁厚/悬垂数值**：本机 trimesh/scipy 未装，dfam-check 暂不可跑。按提示词自身的诚实规则输出："无法确认，需要人工/切片软件进一步检查。"不要猜。
5. **发现问题不修**：外观/结构类问题 → 走 Step 5 重生成（路由见文末）；本检查只做"发现→定位→定级→建议"。

---

以下为体检提示词正文（十六节 + 本机新增第十七节）：

请对当前 Blender 场景中的人物手办模型进行一次完整的「3D打印前模型体检」。

注意：不要修改模型。只检查、分析、报告问题。

检查目标：

1. 人物形体是否完整
2. 几何结构是否正常
3. 是否存在影响3D打印的问题
4. 是否存在AI生成模型常见的结构错误
5. 是否适合后续切片和实际打印

请按照以下顺序检查。

---

## 一、人物整体结构

检查：

- 头、身体、双臂、双手、双腿、双脚是否完整
- 左右身体结构是否存在明显异常
- 四肢是否与身体正常连接
- 是否存在断裂、穿插、悬空
- 是否存在明显不符合人体结构的异常
- 人物姿态是否自然
- 是否存在明显比例异常

特别检查：头身比例、肩宽、手臂长度、腿长、手掌大小、脚部大小。

## 二、脸部检查（重点区域）

检查：双眼完整性、大小是否一致、高度是否一致；眼球/眉毛/鼻子/嘴巴/耳朵/下巴轮廓是否正常；嘴唇是否存在异常穿插。

从正面 / 左45° / 右45° / 左侧面 / 右侧面渲染检查（每视角一张特写渲染图，实际看图）。

重点寻找：五官穿插、五官悬空、左右明显不对称、奇怪凹陷、不自然凸起、AI生成造成的异常结构。

## 三、头发检查

检查：头发与头部是否正常连接；悬空发束；穿透头部；发束互相穿插；异常尖刺；过细发丝；后脑勺是否完整。

特别标记：可能在3D打印中消失的头发细节。

## 四、手部检查（左右分别）

检查：手指数量、粘连、穿插、变形；手掌结构；手腕连接；手指是否过细；指间间隙是否足够打印。

发现问题必须给出：左手 / 右手 + 具体位置 + 问题类型。

## 五、脚部检查

检查：双脚完整性；脚趾异常；鞋子完整性；脚踝是否过细；脚与腿连接；脚底能否稳定接触底面；失稳风险。

## 六、服装检查

检查：衣服穿模、与身体异常粘连、边缘破面、袖口/裤脚/衣领完整性、褶皱异常、装饰与主体的连接。

重点检查：衣服薄边是否薄到无法3D打印。

## 七、配饰检查

对眼镜、耳环、项链、手表、帽子、发饰、手持物等逐项判断：是否存在、是否完整、与主体连接、穿插、过细、是否可能在打印/拆支撑/后处理中损坏。

## 八、几何体检查（本机适配：跑脚本，不靠视觉）

对 Non-Manifold、Boundary Edges、Holes、Duplicate/Internal/Loose/Floating Faces、Self Intersection、Zero Area/Length、重叠几何、法线异常等：

**执行方式**：跑 `repair_for_print.py --mode diagnose`（见文首适配要点2），把输出的开放边数、非流形边数、连通块数、体积符号填入报告。脚本没覆盖的项（自交、零面积细分）按"无法确认，需要人工/切片软件进一步检查"处理，最终数值闭合由段C 的 print_gate 完成。

## 九、实体性检查

模型是否封闭实体；内部空洞；无法解释的内部几何；悬空结构；单层面薄片；零厚度结构。多 Object 时分别检查并报告每个的名字。

## 十、薄壁与打印细节检查

重点寻找：过薄墙体、过细手指/头发/衣服边缘/饰品/眼镜/鞋带/装饰。

每个疑似风险报告：位置 + 类型 + 当前尺寸（能量则量，量不出就写"无法确认"）+ 建议最小尺寸（FDM 0.4 喷嘴经验值：常规件≥1.2mm，装饰细节≥0.8mm）。

不要为了通过检查而修改模型。

## 十一、悬空结构检查

检查头发、手臂、手指、衣服、饰品、手持物、脚部等突出结构是否明显悬空、是否需要支撑。

特别标记：支撑会直接接触脸部、手部、头发、衣服正面等高可见区域的位置。

## 十二、打印方向检查

根据当前姿态分析：打印方向是否合理；哪里会产生大量支撑；哪里适合做支撑区；哪里应避免支撑；哪里易打印失败、易因层间结合不足断裂。

只提建议，不改方向。

## 十三、重心与稳定性检查

判断：重心大致位置；双脚与地面接触情况；能否独立站立；是否需要底座；易倾倒结构。需要底座时指出建议连接位置。

## 十四、AI生成模型专项检查

重点寻找：多余/融合手指、融合衣服/头发、五官穿插、耳朵异常、眼镜变形、饰品融合、身体内部残留几何、不合理孔洞/凸起、局部拓扑异常、左右不一致、看起来正常但无法打印的结构。

## 十五、问题严重程度

- 🔴 P0 必须修复：无法正常打印、严重破坏结构、明显打印失败
- 🟠 P1 强烈建议修复：能打但明显影响质量/强度/外观
- 🟡 P2 建议优化：影响细节/后处理/观感但不影响打印
- 🟢 P3 无需处理：正常模型特征

## 十六、最终输出格式

汇总为四张表（P0/P1/P2/P3），列：编号| 位置| 问题| 原因| 建议。

最后给出：

```
模型体检结果
几何完整性：通过 / 存在问题
人物结构：  通过 / 存在问题
脸部：      通过 / 存在问题
手部：      通过 / 存在问题
服装：      通过 / 存在问题
配饰：      通过 / 存在问题
打印性：    通过 / 存在问题
支撑风险：  低 / 中 / 高
稳定性：    通过 / 需要底座
综合状态：  🟢 可切片 / 🟡 修复后再切片 / 🔴 暂不切片
```

硬性要求：不自动修改模型；只做发现→定位→定级→建议；量不准的明确写"无法确认，需要人工/切片软件进一步检查"；不猜测。

## 十七、单位与缩放检查（本机新增）

这是本链路实测头号翻车点，必查：

- 场景单位是否 Metric + Millimeters（Blender 默认米制，切片器要毫米，不设就是 1000 倍误差）
- 对象缩放是否已应用（Ctrl+A > Scale；未应用的缩放导出尺寸不对）
- 模型实际尺寸是否符合预期（对比目标高度，如 180mm 手办）
- 原点是否在底部中心（影响切片摆放）

任何一项不对 → 直接 P0。

## 问题路由（检查完看这里）

| 发现的问题类型 | 去向 |
|---|---|
| AI 解剖学缺陷（融合手指、五官穿插、悬空发束、左右不对称） | 段A **重生成**（随机性能一次修掉多数瑕疵，比网格手术便宜） |
| 几何/水密/尺寸/原点问题 | 段C **print_gate --autofix**（L1 轻修复 → L2 体素，自动复检） |
| 摆姿/重心/支撑风险 | 切片阶段处理（调摆放、树状支撑），不改模型 |
| 壁厚/悬垂数值 | 切片软件复核（本机暂无 trimesh 测量能力） |
